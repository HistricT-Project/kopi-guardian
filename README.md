Kopi Guardian is a 2D arena survival game: you are the guardian of a coffee garden, holding back waves of pests for 10 waves with a coffee-bean sprayer. Move with WASD or the arrow keys, aim with the mouse, dash with Space or Shift, collect cherries for score and health, level up and pick one of three upgrades each level, chain kills into combos, and defeat the Kumbang Raja boss on wave 10 to save the harvest. Sound is synthesised live with WebAudio, and the whole game runs offline in a desktop browser with zero network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
